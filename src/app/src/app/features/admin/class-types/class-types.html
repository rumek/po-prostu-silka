Typ zajęć definiujesz raz — nazwa i opis obowiązują wszystkie zajęcia tego typu, także te już odbyte. Czas trwania i liczba miejsc to wartości domyślne: zajęcia dostają ich kopię przy tworzeniu i można ją tam zmienić. Typów się nie usuwa — dezaktywacja znika z wyboru, a zaplanowane zajęcia zostają nietknięte.
